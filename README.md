# Banking Microservices

A production-style Banking Microservices application built using Java, Spring Boot, Spring Security, JWT, PostgreSQL, Eureka, API Gateway, Kafka, Docker and Microservices architecture.

## Tech Stack

- Java 25
- Spring Boot 4.1
- Spring Security
- JWT Authentication
- PostgreSQL
- Spring Data JPA
- Eureka Discovery Server
- Spring Cloud Gateway
- Swagger/OpenAPI
- Kafka (Upcoming)
- Docker (Upcoming)
